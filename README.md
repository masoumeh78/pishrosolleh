# 🏗️ PishroSolleh — Industrial Marketplace

A dedicated digital platform for buying and selling second-hand sheds (سوله‌ها) and industrial steel structures (آهن‌آلات). This project was developed to bridge the gap between industrial suppliers and construction businesses using AI-accelerated workflows.

🔗 **Live Demo:** https://masoumeh78.github.io/pishrosolleh/

---

## 🌟 Project Vision
The industrial market for second-hand steel and sheds is often fragmented. **PishroSolleh** provides a streamlined, accessible interface for listing structures, viewing specifications, and connecting sellers with buyers. This project demonstrates my ability to take a real-world business need and transform it into a functional, deployed web application.

## 🤖 AI-Accelerated Development
This project was built leveraging a modern **AI-Native development approach**. By utilizing cutting-edge tools, I significantly optimized the development cycle:
* **Manus & Qwen:** Used for rapid prototyping of UI components and architectural brainstorming.
* **Gemini:** Leveraged for code refactoring, complex logic implementation, and ensuring clean, scalable code.
* **Result:** A fully functional, responsive, and performance-optimized platform built with high velocity without compromising on quality.

## ✨ Key Features
* **Industrial Catalog:** Organized listing of sheds and steel structures with key technical details.
* **Responsive Layout:** Optimized for both mobile devices (on-site usage) and desktop interfaces.
* **SEO & Performance Focused:** Clean HTML/CSS structure to ensure accessibility and fast load times.
* **User-Centric Design:** Simple navigation to facilitate quick decision-making for buyers.

## 🛠️ Tech Stack
* **Core:** HTML5, CSS3, JavaScript
* **AI-Tools:** Manus, Qwen, Google Gemini
* **Hosting:** GitHub Pages
